# URL-to-Host-IP-Address-Finder
created a web application that uses a website's URL to determine its IP address. The program translates a domain name into its matching host IP address using DNS (Domain Name System) resolution. It presents the resolved IP address in an easy-to-use interface, checks user input, and gracefully handles invalid URLs.

Key Features:

Accepts a website URL as input.
Resolves the domain name to its host IP address.
Displays the IPv4/IPv6 address (if available).
Validates URLs and handles invalid or unreachable domains.
Simple and responsive user interface.

Technologies Used:

Frontend: HTML, CSS, JavaScript
Backend: Java (or mention your backend language/framework, e.g., Spring Boot if applicable)
Networking: DNS Lookup, Java InetAddress API
